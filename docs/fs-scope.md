# 文件系统范围（决策记录）

## 结论（2026-08-13 默认采用，可调整）

**SAF 授权目录为主 + 应用私有目录兜底**

- 首次启动弹出系统目录选择器（ACTION_OPEN_DOCUMENT_TREE），用户授权一个根目录（如 /sdcard/Desktop）
- `takePersistableUriPermission` 持久持有授权，重启免再选
- 未授权时（用户跳过/首次启动瞬间）自动回退到应用私有目录 `filesDir/root`，App 照常可用
- 授权变更后前端收到 `App.onRootChanged` 通知并刷新

### 理由

| 方案 | 优点 | 缺点 | 结论 |
|------|------|------|------|
| SAF 授权目录 | Play 合规、持久授权、用户可控、无需特殊权限 | 只能访问授权目录内 | **主方案** |
| 全盘访问（MANAGE_EXTERNAL_STORAGE） | 最像真桌面，任意路径 | Play 上架受限（特殊权限审批）、安全风险大 | 备选（内部使用可切） |
| 应用私有目录 | 零权限、永远可用 | 用户不可见、卸载丢失、不可分享 | 兜底 |

## 对前端的影响

- 所有文件路径为**相对根目录**的字符串，由 Java Bridge 解析，禁止前端拼绝对路径
- 路径校验在桥内：拒绝绝对路径、拒绝 `..` 逃逸
- 前端通过 `App.FileAPI`（Promise 封装）访问，与具体后端（SAF/私有目录）解耦
